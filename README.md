# ganadhik.github.io -- Portfolio Website Source Code

Personal portfolio website showcasing projects, research, and professional experience.

## 🚀 Features

- **Responsive Design**: Works on all devices
- **Curated Projects**: Icon-based cards with external links
- **Research Highlights**: Dedicated academic section
- **Email Contact**: Direct mailto CTA

## 🏗️ Tech Stack

- React + Vite
- Tailwind CSS
- Google Fonts (Space Grotesk, Source Serif 4)

## 📦 Installation

### Prerequisites
- Node.js 18+

### Local Development

```bash
npm install
npm run dev
```

## 🌐 Deployment

### GitHub Pages
1. Push to GitHub
2. Enable GitHub Pages in repository settings
3. Site will be live at `https://adhikariganesh9813.github.io`
