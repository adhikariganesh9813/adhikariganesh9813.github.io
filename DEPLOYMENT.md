# Quick Deployment Guide

## Install gh-pages Package

```bash
npm install --save-dev gh-pages
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This will:
1. Build your optimized production site
2. Deploy it to the `gh-pages` branch
3. Make it live at: https://adhikariganesh9813.github.io/Personal-Website-/

## After Deployment - Submit to Google

1. **Google Search Console**: https://search.google.com/search-console
   - Add property: `https://adhikariganesh9813.github.io/Personal-Website-/`
   - Verify ownership
   - Submit sitemap: `https://adhikariganesh9813.github.io/Personal-Website-/sitemap.xml`

2. **Bing Webmaster Tools**: https://www.bing.com/webmasters
   - Add site
   - Submit sitemap

## Monitor Rankings

Check Google Search Console after 3-7 days to see if your site is indexed.

Your site should start appearing in search results for:
- "Ganesh Adhikari"
- "Ganesh Adhikari data engineer"
- "Ganesh Adhikari Texas Tech"

And other related searches within 1-2 weeks!
